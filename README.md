# Sam's Security Vault
CLI credential manager with AES-256 Encryptio

# Overview
A Python-based CLI tool for DevSecOps enthusiasts to securely manage password, API keys, and tokens with a high level encryption 

# Key Features

- **High-Level Encryption**: AES-256-GCM with authenticated Encryption
- **Secure key derivation**: PBKDF2 with 100,000+ iterations
- **Memory Safety**: No plaintext credentials ever written to disk 
- **Clean CLI**: Rick terminal interface with user validation
